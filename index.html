Quantum compilation and diagnostics

Fidelity attribution that holds across compiler phases, SDKs, and devices, so that loss in a compiled circuit can be located rather than only measured end to end.

Quantum and HPC runtime systems

Under India's National Quantum Mission (NQM), resource-aware execution policies and application-aware recovery for hybrid scientific workflows, connecting device-level evidence to runtime decisions.

Quantum data systems

Admission, costing, and recovery for SQL-to-quantum query plans, so that a plan is validated before it runs and an answer is released only when it meets the requested precision.
